# 窗口守門人：美沙冬給藥窗口的一夜

實習生美沙冬替代療法（MMT）課程的課後網頁小遊戲。玩家扮演給藥窗口的藥師，連續值班三晚：核對身分與處方、觀察病人服藥，並在月底完成盤點。

## 開始玩

- 線上版：<https://rockyang0826.github.io/window-guard/>
- 單一 HTML 檔，不需安裝。電腦、手機都能玩（含 iOS 16 Safari）。

## 內容說明

- 角色、姓名、證件與病歷皆為虛構。
- 規則中的天數與流程為教學示例，實際依本院作業規範。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 遊戲本體（HTML、CSS、JavaScript 都在同一個檔案） |
| `.nojekyll` | 讓 GitHub Pages 直接提供檔案，不經過 Jekyll 處理 |
